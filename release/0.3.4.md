# Audiora 0.3.4

发布日期：2026-10-22。

## 更新内容

- Android 新增应用内下载与安装更新：检查到新版本后以底部面板展示版本与更新说明，点击「立即更新」即可在应用内下载安装包并调起系统安装器，不再需要跳转浏览器手动下载。
- 下载进度与安装入口整合进「关于与更新」页：确认更新后面板收起，下载进度（百分比、已下载/总大小）显示在页面卡片中；离开页面或关闭面板不会中断下载，安装包就绪后显示「更新包已下载」，由用户主动点击安装。
- 下载任务支持进度显示、主动取消与失败重试；取消会等待临时文件清理结束才允许重新下载。安装权限被拒或安装器调用失败时可复用已下载的安装包，安装包失效或被系统清理时自动重新下载。
- 沿用国内 GitHub 加速线路与主题语义色；更新状态仅保留在当前进程，应用冷启动时自动清理上次的安装包与未完成下载，每次下载前清理同名旧包，避免缓存累积。

## 兼容说明

- 应用内更新仅支持 Android，iOS 沿用原有外部下载流程。
- 正式包使用包名 `io.github.yingjiedev.audiora`、arm64-v8a 架构与既有发布证书，可覆盖安装同签名正式版。
- 发布信息未提供安装包大小时，确认面板仅显示版本号；下载开始后显示服务端报告的实际大小。
- 更新状态不跨进程保留：下载过程中被系统回收或强杀后需重新发起下载。
- 真机视觉与交互由用户手动验收；浅色、深色与自定义主色下的对比度已有自动覆盖，但不替代设备实测。
