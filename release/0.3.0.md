# Audiora 0.3.0

## 更新内容

- 统一首页、音乐库、“我的”和歌曲列表。首页听歌卡随机使用昼夜外观，收藏侧页完整折叠；两种卡片的超长歌名单行滚动。
- 整合底部播放栏与完整播放器，优化展开过渡、队列、歌曲历史与歌单播放历史。
- 新增设备本地听歌趋势、收听时长和活跃日历。统计从首次使用新版开始，不补造历史数据。
- 新增榜单随机拾音，优化候选池刷新与最近播放排除。
- 支持插件自定义显示名，适配音质协议，改善取源失败及超时处理。
- 重整下载管理与历史分栏，支持独立封面保存；重装或导入后重新关联本地歌词与封面。
- 显示本地音频实际音质，优化分类、范围搜索、音乐管理及设置入口。
- 改善浅色、深色与自定义主题的可读性，统一控件布局。

## 兼容说明

- 移除内置固定解包材料，旧加密曲目需要能提供可播放音源的插件支持。
- 既有收藏、播放历史与主题设置保留；听歌统计仅保存在当前设备，尚未纳入既有歌单备份。
- Android 发布目标为 arm64-v8a。正式 APK 使用既有发布证书；本地验证构建使用测试证书，不能代替正式发布产物。
