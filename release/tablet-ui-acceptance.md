# 平板适配：实现与验收

关联：Audiora [#144](https://github.com/yingjiedev/audiora/issues/144)、MusicFree [#317](https://github.com/maotoumao/MusicFree/issues/317)。实现基于 `a7ea3a5f`（0.3.4），研究记录见 [调研文档](../docs/design/tablet-adaptation-research-20261025.md)。

## 已实现

- 控件几何缩放与公共字体共同封顶到 430dp 基准；手机尺寸仍按原有短边比例。768dp 短边下，普通歌曲行最小高度基准由 122.88 降为 68.8dp。`vw/vh/vmin/vmax` 继续表达真实窗口大小。
- 在修改缩放公式前，将面板内部的全宽尺寸迁到百分比；宿主面板单独根据窗口尺寸和安全区决定宽高，横向大窗侧面板最大宽度 480dp。弹窗最大宽度 560dp，Toast 最大宽度 480dp。
- 单一导航容器和单一内容 Navigator。600dp 起使用 80dp 导航轨；1200dp 起展开到 224dp。目的地仍为首页／音乐库／我的，另有搜索与设置。
- 大屏跨子页面显示播放条，共用现有播放、喜欢、进度和队列操作。手机保留现有 PlayerDock；文件选择、批量编辑、权限和自定义主题全屏流程不显示大屏外壳。
- 空间足够时，可展开歌词／队列辅助栏。导航轨下至少需要约 944dp；窄窗不会强塞辅助栏，也不会清空其选择状态。辅助栏为非模态内容，完整播放器仍是模态 Overlay。
- 完整播放器在宽度至少 840dp、高度至少 480dp 时支持封面／控制与歌词／队列并排，包括宽度足够的竖向平板。原手机横屏呈现继续保留。
- 首页卡片、在线榜单、近期内容、搜索发现、媒体网格、艺术家／榜单 TabView 等根据主内容区宽度计算。歌单／专辑主内容区至少 900dp 时，元信息与歌曲列表并排；列表与勾选状态跨布局变化保留。
- 首页三个分区按需首次挂载，访问后保留组件与其本地状态；切换底栏、侧栏或分屏不丢失已访问分区的筛选与位置。
- 普通设置表单限制到 720dp 阅读宽度。新界面复用语义主题色，歌词使用既有媒体深色表面，不修改主题设置、字体偏好或播放存储格式。

音乐库分组与详情的进一步双栏组织、系统大字体全面支持、键鼠快捷键、拖拽调整栏宽和铰链感知不在此次实现范围。

## 自动验证

本地 Windows 验证记录，2026-10-25：

- 完整 Jest：200 个套件、1576 项通过；随后新增的首页状态与相关改动定向回归：6 个套件、20 项通过。
- `npm.cmd run test:colors`：29 个套件、354 项通过；新播放条另有深／浅模式及自定义播放表面前景对比度测试。
- `npm.cmd run check:colors`：通过，硬编码颜色基线维持为零，未扩大豁免。
- `npm.cmd run check:ui`：通过，现有规则发现数从基线 128 降至 108。
- `npm.cmd run check:motion`：动画回调与原生桥接 worklet 检查通过。
- `npm.cmd run lint -- --no-fix`：零错误，110 条警告；变更文件另外执行 ESLint 自动修正与检查。
- `npm.cmd run typecheck:runtime`：通过。
- Android release 模式 JS bundle 与资源打包：通过。此项不等于 APK 或原生编译通过；Metro 仍输出项目既有配置提醒。
- 完整 `tsc --noEmit` 受项目既有 RN 配置导出子路径问题影响。用相同项目选项显式加载已安装 RN 配置，对变更前后的源内容进行比较，均为 51 条既有诊断，新增诊断为零；不记作全仓 TypeScript 检查通过。

## 待用户真机验收

没有生成 APK、安装应用、启动模拟器或采集设备截图。本次修改不改变原生配置；Android／iPad 原生布局、手势、窗口行为仍待验证。

| 场景 | 检查内容 |
| --- | --- |
| 手机窄窗，例如 390×844 | 底栏、小播放器、首页卡片与原有主要操作保持可用 |
| 600–839dp 竖向窗口 | 导航轨、歌曲行和网格密度；长标签不遮挡；不出现过窄的辅助栏 |
| 1024×768、1280×800 | 主导航、跨页面播放、辅助栏开合、歌单信息／列表并排 |
| 同一平板连续分屏、旋转 | 当前歌曲、暂停状态、队列、搜索来源、勾选和已访问首页分区状态保留 |
| 完整播放器与辅助栏 | 背景浏览可用；完整播放器打开后背景不能点击；只有当前歌词视图执行滚动；退出与返回顺序正确 |
| 队列、弹窗和键盘 | 排序、移除、添加歌单、表单输入、键盘避让与多层模态返回 |
| 浅色、深色、自定义／动态主题 | 导航状态、播放条文字、喜欢、歌词、队列和透明背景的真实合成效果 |
| iPad 与外接输入 | 安全区、多窗口、焦点、屏幕阅读器；本次未进行 iOS 编译或原生验收 |
