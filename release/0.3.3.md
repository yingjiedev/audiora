# Audiora 0.3.3

发布日期：2026-10-20。

## 更新内容

- 新增「云光浅色」与「沉浸深蓝」两款 Android 桌面小部件，可独立添加、同时使用；展开布局提供拾音和播放控制，缩小后保留紧凑播放器。
- 小部件支持在后台及进程被回收后恢复播放器，保留播放进度、暂停状态与用户操作；从桌面打开应用后继续共用当前播放队列。
- 接入 Android Auto，支持浏览当前播放列表、点歌、恢复/暂停、上下首、停止、进度跳转和当前列表语音匹配，手机与车机共用播放会话。
- 新增 WebDAV 每日或每周自动备份，应用在前台时按周期检查，启动、回到前台及网络恢复时补做；设置页显示最近成功时间、失败状态，并提供备份说明面板。
- 插件新增 `require("musicfree/storage")` 持久化存储接口，按插件原始平台名称隔离；重启应用或更新插件保留数据，插件管理支持重置插件数据。
- 优化播放历史面板的展开时机、Android 硬件加速和列表加载，减少弹出时的卡顿与残影。

## 兼容说明

- 桌面小部件与 Android Auto 仅支持 Android。小部件使用系统标准入口，小米设备可从「传统小部件」添加；尚未接入小米小部件中心。
- Android Auto 提供当前队列浏览与语音匹配，尚未实现全部歌单/收藏浏览、插件全网语音搜索或独立 Android Automotive OS 应用；侧载测试可能需要在 Android Auto 开发者选项中允许未知来源。实际车机兼容与连接行为仍待用户验收。
- WebDAV 自动备份默认关闭，需先配置服务器；后台或关闭应用期间不会独立唤醒，下次回到前台检查补做。备份仍覆盖同一云端文件，包含歌单、插件地址和音效设置，不包含音频、插件持久化数据或 WebDAV 密码。
- 插件存储能力需要插件主动调用；单条记录最多 1 MiB、全部插件合计 10 MiB，卸载最后一个同平台插件时清除对应数据，不提供跨设备同步。
- Android 正式包使用包名 `io.github.yingjiedev.audiora`、arm64-v8a 架构与既有发布证书，可覆盖安装同签名正式版。
- iOS IPA 由发布流水线构建，未进行 Apple 代码签名，需要自行签名安装；iOS 原生界面尚未实机验证。
- 小部件与播放历史面板已有用户对预览包的手动反馈；完整正式包的原生界面、WebDAV 服务端操作和车机功能仍由用户完成验收。
