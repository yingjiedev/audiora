# Audiora 0.3.2

发布日期：2026-10-18。

## 更新内容

- 新增音效馆，提供原声、人声、低音、明亮、柔和、流行、摇滚、爵士、古典、电子十种均衡器预设；可按设备实际支持的频段调整曲线和前级增益。
- 支持创建、另存、重命名和删除多套自定义音效预设；未播放或关闭音效时也可编辑保存，播放开启后试听。
- 本地与 WebDAV 备份包含音效配置及自定义预设，恢复时按目标设备频段适配；旧版单个自定义预设自动迁移。
- 搜索、歌单、专辑、歌手、本地音乐与播放历史等列表支持在原页面多选和批量操作，保留当前滚动位置、来源与分页状态；分页新增歌曲默认不选中。
- Android 12 及以上设备支持系统莫奈动态配色，跟随系统壁纸和深浅模式变化；自定义主题配置继续保留。
- 检查更新与下载安装包时自动选择可用的 GitHub 直连或加速线路，通过小范围下载测速改善更新体验。

## 兼容说明

- 音效处理目前支持 Android 音乐播放，实际可用频段及前级能力取决于设备；其他平台保留导入的配置，供后续备份使用。
- 音效备份恢复沿用现有非事务流程：音效写入失败会报告失败，已经恢复的歌单或插件不会回滚；旧备份未包含音效时保留当前配置。
- 系统动态配色需要 Android 12 或以上及设备支持；不可用时沿用既有主题，自定义主题仍使用用户设置。
- Android 正式包使用包名 `io.github.yingjiedev.audiora`、arm64-v8a 架构与既有发布证书，可覆盖安装同签名正式版。
- iOS IPA 由发布流水线构建，未进行 Apple 代码签名，需要自行签名安装。
- 原生 UI、主题、手势与音效听感的最终验收由用户完成，自动测试不代替真机验收。
