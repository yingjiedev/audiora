# Audiora 0.3.1

发布日期：2026-10-17。

## 更新内容

- 新增多音源聚合搜索，合并同曲结果；优化搜索发现、历史记录、增量分页和大量音源下的等待反馈。
- 搜索页展示各音源的完成、失败与配置状态，可单独重试、继续搜索未完成的来源或补全插件配置。
- 收藏支持关联同曲的多个音源、选择播放来源，并在播放失败后尝试已关联的其他来源；收藏关联与偏好可随备份导出、恢复。
- 修复随机播放卡住、下一首无响应及连续取源失败后反复跳曲的问题；手动切歌或暂停后，旧请求与延迟跳转不再干扰新操作，重复结束事件只推进一次。
- 迷你播放器的播放／暂停图标新增渐变进度填充；统一播放页上下滑动及返回过渡。
- 首页收藏预览展示播放次数与歌曲信息，修复卡片折叠圆角和背面残影。
- 统一歌单、搜索、下载、听歌报告与设置等子页面；支持在原列表勾选歌曲、全选及批量操作。
- 恢复插件订阅更新入口，保留订阅列表，完善更新进度、结果与错误反馈。

## 兼容说明

- 原有单来源收藏继续兼容；新增的多源关联由用户确认，不改变插件原始歌曲身份。
- 播放失败换源遵循既有设置。默认最多连续自动跳过 3 首失败曲目，之后停止并提示；当前真实曲目进入播放状态后重置失败计数。
- Android 正式包使用包名 `io.github.yingjiedev.audiora`、arm64-v8a 架构与既有发布证书，可覆盖安装同签名正式版。独立预览版继续使用单独包名。
- iOS IPA 由发布流水线构建，未进行 Apple 代码签名，需要自行签名安装。
- Android 原生 UI、主题、手势与实际插件播放的最终验收由用户完成，自动测试不代替真机验收。
