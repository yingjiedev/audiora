## 实现

- 搜索与定时行继续保留；下方新增“推荐 / 我的收藏 / 榜单”三个页内入口。当前入口使用主题主色与 onPrimary，滚动时吸顶并按实际章节位置更新选择。跳转扣除导航高度；无榜单来源时进入现有完整榜单页面。
- 主卡左侧增加独立可点的收藏折页，显示真实收藏封面与数量，直接进入原默认收藏歌单。无封面时使用现有音乐图标。
- 折页以右侧为轴，默认 -18°，横滑逐步收拢到 -38°，越界钳制；使用原生 UI 线程滚动值。系统减少动态效果时取消透视，保留完整平铺功能。
- 主卡与折页合计宽度仍限制为屏幕约 76%，下一张拾音卡宽度约 62%，留出可辨认的侧边预览；末尾补足实际可滑动空间，保证最后一张可完整对齐。封面 164rpx，普通圆角及间距沿用 designSystem。主卡改为上方封面、下方歌名与作者/来源，播放按钮是独立点击区域。
- 收藏、榜单和既有快捷入口继续使用实际数据、完整收藏播放队列、原有缓存和异常处理。音乐库、我的、底部播放器及用户主题配置没有修改。
