# “我的”页面设计说明

本次以用户提供的个人页截图作为信息层级参考，重构 Audiora 的原生页面。目标是让收藏、听歌记录和歌单成为页面重点，保留原有功能，不引入参考产品的会员、金币、签到、社交资料或品牌元素。

## 布局与差异

- 顶部使用 Audiora 标识及主题派生的蓝色调表面；“我喜欢”的歌曲数与真实歌单封面组成不对称主入口。它是音乐收藏入口，不模拟账号、会员或收益卡片。
- 历史、下载与收藏歌单采用三个等宽的简洁图标入口，去掉原来的独立双列功能卡片。下载完整说明保留在无障碍提示中。
- 最近播放展示最近六首歌曲的独立封面、两行歌名和作者；封面上的播放图标属于同一个歌曲按钮。点击继续播放原始歌曲，查看全部打开既有历史抽屉。预览限制不删除或截断存储记录。
- “我的歌单”专注自建歌单；默认“我喜欢”移到顶部主入口。所有自建歌单保留在列表中，导入、ID 播放、新建与完整歌单浏览均可直接进入。
- 备份与恢复、关于与更新收在页面下部的工具列表。版本号允许完整换行，设置入口仍在固定页头。

| 原有功能 | 新布局位置 | 路由或操作 |
| --- | --- | --- |
| 设置 | 页头 | 设置概览 |
| 我喜欢 | 主卡片 | 默认本地歌单详情 |
| 播放历史 | 快捷入口、最近播放“查看全部” | PlayList 的 history 标签 |
| 下载管理 | 快捷入口 | 下载页面 |
| 收藏歌单 | 快捷入口 | starred 歌单浏览 |
| 导入 / ID 播放 / 新建 | 歌单工具条 | 原有三个面板 |
| 歌单详情 / 查看全部 | 歌单列表及标题右侧 | 原始歌单 ID、local 歌单浏览 |
| 备份与恢复 / 关于与更新 | 音乐工具 | 原有设置子页 |

## 视觉约束

遵守 [COLOR_SYSTEM.md](../../COLOR_SYSTEM.md)。主卡片使用 `tonalSurface` / `onTonal`，喜欢图标使用 `favorite`；其他控件使用 `primaryText`、中性前景和现有表面。图片上的播放徽标使用 `inverseSurface` / `onInverse`。没有新增原始色值、主题配置或图片素材；标识、封面回落图、矢量图标和字体均沿用仓库资源。

复用 `designSystem` 的间距和圆角。主操作至少 44dp，歌单工具条可换行，歌曲标题最多两行，版本号不设行数上限。浅色、深色和自定义主色的主卡片文字及喜欢图标有对比度回归检查。未知自定义壁纸上的实际可读性仍需真机检查。

本页使用参考图的内容组织思路；蓝色调音乐收藏主卡片、三入口布局、独立歌曲封面及工具分组均为 Audiora 的具体设计选择。没有复制对方品牌、专属图形或商业模块。

## 验证与交付

功能测试覆盖全部原有目的地、三个管理面板、历史入口、点击播放及来源标识、空状态、动态数量、插件显示名和长版本号。颜色回归纳入 `npm run test:colors`。

原生视觉验收交给用户：按仓库要求，在预览包安装并确认版本后停止，不自动采集截图或代替用户进行验收。重点检查默认主题、深色主题、一个自定义主题，以及无历史 / 无自建歌单、长歌名、长版本号和底部播放器展开后的滚动可达性。
