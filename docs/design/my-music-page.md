# “我的”页面设计说明

本次以用户提供的个人页截图作为信息层级参考，重构 Audiora 的原生页面。目标是让收藏、听歌记录和歌单成为页面重点，保留原有功能，不引入参考产品的会员、金币、签到、社交资料或品牌元素。

## 布局与差异

- 顶部使用紧凑的中性表面收藏卡，Audiora 标识和辅助说明降低分量。“我喜欢”的封面、名称和小字号真实数量组成横向入口；不模拟账号、会员或收益卡片。
- 历史、下载与收藏歌单采用三个等宽的简洁图标入口，不为图标加独立白色底块。完整触摸区仍不少于 44dp，下载完整说明保留在无障碍提示中。
- 最近播放展示最近六首歌曲的独立封面、两行歌名和作者；封面上的小播放图标属于同一个歌曲按钮。封面根据实测容器宽度排布，普通手机显示三个完整封面和少量下一项；窄屏优先保证封面可读，宽屏最多四项。统一标题区域高度使长短歌名下的作者对齐。点击继续播放原始歌曲，查看全部打开既有历史抽屉。预览限制不删除或截断存储记录。
- “我的歌单”专注自建歌单；默认“我喜欢”保留在顶部主入口。所有自建歌单保留在列表中，导入、ID 播放、新建汇入一条轻量工具栏，完整歌单浏览仍可直接进入。零自建歌单以简短说明展示，不再加一张大的空卡。
- 备份与恢复、关于与更新收在页面下部的低强调工具列表。预览版显示简短版本及预览标识，完整安装版本在关于页和入口的无障碍提示中保留；正式版及其他版本原样显示。设置入口仍在固定页头。

| --- | --- | --- |
| 设置 | 页头 | 设置概览 |
| 我喜欢 | 主卡片 | 默认本地歌单详情 |
| 播放历史 | 快捷入口、最近播放“查看全部” | PlayList 的 history 标签 |

## 视觉约束

遵守 [COLOR_SYSTEM.md](../../COLOR_SYSTEM.md)。收藏卡使用 `card` / `text`，辅助说明使用 `textSecondary`，数量局部使用 `primaryText`。封面优先使用自定义歌单封面或真实收藏歌曲的封面；缺少封面时使用小面积 `tonalSurface` 和 `favorite` 矢量图标，去掉重复的 3D 红心。图片上的播放徽标使用 `inverseSurface` / `onInverse`。没有新增原始色值、主题配置或图片素材；标识、封面回落图、矢量图标和字体均沿用仓库资源。

复用 `designSystem` 的间距和圆角，页头和内容统一使用 32rpx 左右边距。收藏卡从原来的约 272rpx 压缩到约 208rpx，数量不再使用 hero 字号。主操作至少 44dp，歌单工具条可换行，歌曲标题最多两行并预留一致行高。浅色、深色和自定义主色的卡片中性前景、数量和缺图喜欢图标有对比度回归检查。未知自定义壁纸上的实际可读性仍需真机检查。

本页使用参考图的内容组织思路；紧凑的音乐收藏卡、三入口布局、独立歌曲封面及工具分组均为 Audiora 的具体设计选择。没有复制对方品牌、专属图形或商业模块。

## 验证与交付

功能测试覆盖全部原有目的地、三个管理面板、历史入口、点击播放及来源标识、空状态、动态数量、插件显示名、完整版本身份、真实收藏封面回落和容器宽度更新。布局回归验证完整封面、下一项提示、窄屏和宽屏的排布。颜色回归纳入 `npm run test:colors`。

原生视觉验收交给用户：按仓库要求，在预览包安装并确认版本后停止，不自动采集截图或代替用户进行验收。重点检查默认主题、深色主题、一个自定义主题，以及无历史 / 无自建歌单、长歌名、长版本号和底部播放器展开后的滚动可达性。
