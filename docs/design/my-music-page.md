# “我的”页面设计说明

本次以用户提供的个人页截图作为信息层级参考，重构 Audiora 的原生页面。目标是让收藏、听歌记录和歌单成为页面重点，保留原有功能，不引入参考产品的会员、金币、签到、社交资料或品牌元素。

## 布局与差异

- 顶部使用一张中性表面收藏卡，只突出“我喜欢”的真实封面、名称、数量和进入箭头。Audiora 标识缩为页头的辅助标记，去掉卡内的宣传介绍；不模拟账号、会员或收益卡片。
- 播放历史、下载管理、收藏歌单、插件管理依次采用四个等宽的简洁图标入口，不为图标加独立白色底块。插件数量订阅现有 `usePlugins()`，点击直接进入既有插件管理页，零插件仍可打开。完整触摸区仍不少于 44dp，下载与插件完整说明保留在无障碍提示中。
- 最近播放展示最近六首歌曲的独立封面、一行歌名和一行作者；封面上的小播放图标属于同一个歌曲按钮。封面根据实测容器宽度组成完整页，普通手机每页三项，窄屏两项或一项，原生横向分页在停止滑动时对齐整页，不露出下一项零碎文字。最后一页不足三首仍完整保留；宽度变动重新布局。单行标题保持作者对齐并去掉短标题下的空档，完整标题保留在无障碍名称中。点击继续播放原始歌曲，“全部”打开既有历史抽屉。预览限制不删除或截断存储记录。底部播放器继续按原有需求滚动歌曲信息，不采用本页的标题截断规则。
- “我的歌单”专注自建歌单；默认“我喜欢”保留在顶部主入口。所有自建歌单保留在列表中，导入、ID 播放、新建保留三个独立操作，去掉整行白色底板，新建使用主题主色胶囊突出。完整歌单浏览仍可直接进入。零自建歌单只保留一条有效说明，不重复展示大空卡或“还没有”的标题。
- 备份与恢复、关于与更新收在页面下部的低强调工具列表。预览版显示简短版本及预览标识，完整安装版本在关于页和入口的无障碍提示中保留；正式版及其他版本原样显示。设置入口仍在固定页头。

## 视觉约束

遵守 [COLOR_SYSTEM.md](../../COLOR_SYSTEM.md)。收藏卡使用 `card` / `text`，辅助说明使用 `textSecondary`，数量局部使用 `primaryText`。封面优先使用自定义歌单封面或真实收藏歌曲的封面；缺少封面时使用小面积 `tonalSurface` 和 `favorite` 矢量图标，去掉重复的 3D 红心。图片上的播放徽标使用 `inverseSurface` / `onInverse`。没有新增原始色值、主题配置或图片素材；标识、封面回落图、矢量图标和字体均沿用仓库资源。

复用 `designSystem` 的间距和圆角，页头和内容统一使用 40rpx 左右边距。收藏卡采用约 152rpx 的单行结构、112rpx 封面和 20rpx 内边距，按内容自然增高。页头 36rpx/700、分区 30rpx/600、歌名 26rpx/500、作者 20rpx/400、工具名称 24rpx/500、工具说明 18rpx。收藏大卡 28rpx、内容图 22rpx、次级工具组 16rpx 圆角。最近播放页内间隔 24rpx，四个快捷图标 44rpx；普通“全部”操作改用次级色。主操作至少 44dp，歌单操作可换行。浅色、深色、自定义主色和半透明主色的新建按钮及卡片前景有对比度回归检查。未知自定义壁纸上的实际可读性仍需真机检查。

本页使用参考图的内容组织思路；音乐收藏主卡、四入口布局、独立歌曲分页及工具分组均按 Audiora 的实际功能设计。没有复制对方品牌、专属图形或商业模块。

## 验证与交付

功能测试覆盖全部原有目的地、三个管理面板、历史入口、第四个插件管理入口及动态数量、点击播放及来源标识、空状态、插件显示名、完整版本身份和真实收藏封面回落。布局回归验证三项整页、两项/一项窄屏重排、最后一页不足三项、完整无障碍标题和容器宽度更新。颜色回归纳入 `npm run test:colors`。

原生视觉验收交给用户：按仓库要求，在预览包安装并确认版本后停止，不自动采集截图或代替用户进行验收。重点检查默认主题、深色主题、一个自定义主题，以及无历史 / 无自建歌单、长歌名、长版本号和底部播放器展开后的滚动可达性。
