# 首页两套听歌卡与完整折页（2026-10-13）

用户选择原设计方向 2「封面视窗」和 3「夜色唱片」，要求随机出现，并明确夜色主卡左侧收藏页也要一起变为深色。修正后的合成确认稿见 [确认稿](evidence/home-dual/approved-dual-appearance.png)，用户已明确授权实施。该图是设计参考，非原生界面截图或动画验收。

## 外观与真实内容

- 封面视窗：上方裁切真实歌曲封面，下方主题卡面承载歌曲、歌手和来源；播放按钮与拾音保持相同的基准位置。图片上的「继续聆听」标签提供独立不透明底，避免任意封面破坏文字对比度。
- 夜色唱片：右上角局部唱片沟槽衬景、大标题、下方小封面与真实歌手/来源。收藏折页、纸面、书脊两侧底色与正文前景一起切换为夜色；播放使用白底图形按钮。
- 拾音：独立浅蓝唱片图片区与主题正文区。继续调用原 `useShiYin` 的榜单队列，保留加载、禁用、异常处理；没有伪造曲目、推荐统计或新的播放通道。
- 播放当前曲目时卡面打开已有播放器，独立按钮暂停/续播；历史歌曲仍播放实际条目，空数据引导到本地音乐。封面与歌曲行使用同一个 `resolveArtwork`，保留已有默认封面。
- 两套共用 344rpx 最小高度、192rpx 上部区、152rpx 下部区及圆角；文字正常参与布局，实际高度由 onLayout 测量。夜色标题使用既有 hero 字号；其余继续使用公共字体与间距系统。

`HomeFeatureDeck` 用一次 `useState` 初始化进行 50/50 选择。首页根组件切换到音乐库或我的时会卸载 HomeBody，回来重新挂载并抽取；本次停留的切歌、收藏数更新、横滑、栏目跳转、布局测量和播放器覆盖层不会重新选择。无轮播定时器、持久化设置改写或跨页换色。

## 动画与停靠

保留双宽透明载体，把 Android 原生中心置于纸页右边铰链；不增加透视矩阵的平移补偿。实际高度的 2.4 倍载体让消失点位于 1.2 倍卡高，减少之前底角下沉过大的变形。滚动进度经连续 smoothstep 映射，在一个纸页宽内完成 0° 至 −180°，起止速度减小，反向拖动使用同一轨迹；每帧只更新 shared offset。

文字在接近侧面时先淡出，纸面继续绕到主卡后方；主卡左圆角从背面阶段恢复，末段清除圆角下残边。底部保留 6.5% 实际卡高，覆盖约 5.72% 最大理想投影下沉。减少动态效果保留可操作平面收藏入口。

紧凑收藏页为 112rpx 上限、复合卡宽度的 23% 上限。末停靠点使用内容真实滚动上限，拾音卡右边缘对齐页面边距，不添加用来强推最后卡片的多余尾部空白。

## 素材与颜色

新素材 `src/assets/imgs/home-discovery-window-v1.png` 为内置 imagegen 按确认稿制作的 1942×809 浅蓝唱片图片区，没有 UI、文字或统计。已在本地打开检查。夜色沟槽复用已有透明 `player-vinyl.png`，不新增另一套图标系统或漂浮云朵。

颜色由 `useColors()` 的新语义字段提供。夜色卡与折页共用可读前景；纹理的最亮潜在叠加面也参与 4.5:1 计算。视窗正文跟随当前主题表面，按钮跟随用户主色。不改写用户主色、透明度、收藏或播放数据；COLOR_SYSTEM.md 已同步，基线/豁免不扩大。
